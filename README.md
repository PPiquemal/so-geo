# So-Geo Technical Standards & Knowledge Base

This repository documents validated, field-proven workflows used at **So-Geo**
for geospatial data preparation, publication and visualization.

The objective is to maintain a **living, version-controlled, practical manual**
that engineers can rely on for repeatable and robust production.

## Scope

- Raster pre-processing (GDAL, COG, EPSG:3857)
- GeoServer publishing standards
- MapStore usage guidelines
- Cesium 3D workflows
- Future: Digital Terrain Model 2D & 3D processes

## Philosophy

✔ Real-world proven  
✔ Reliable and reproducible  
✔ Lightweight and transparent  
✔ Linux-friendly  
✔ Web-mapping optimized
